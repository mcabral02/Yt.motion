# xplain.motion

Animated explainer Shorts, scripted, voiced, animated and captioned by Claude Code agents.

- `pipeline/script.json`: the script (what gets said, scene by scene)
- `pipeline/voice.py`: the narrator (free offline AI voice)
- `pipeline/render.py`: the animator and captioner (draws frames, renders the video)
- `pipeline/test3d.py`: first 3D (Blender) test
- `setup.sh`: one-time install for a new workspace
- `CLAUDE.md`: the channel's rules, read automatically by Claude in every session
